Courier

Courier is a private tool that one person runs on their own computer to read and draft replies in their own Gmail accounts. It is not offered to the public.

Privacy policy

  • Courier accesses Gmail only for accounts its owner connects, using read access and the ability to create drafts. It never sends email.
  • Email data is stored only on the owner's own computer. It is not sold, shared, or sent to any third party, and is not used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Any connected account can revoke access at any time at myaccount.google.com/permissions.
